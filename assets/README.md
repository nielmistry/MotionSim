# Assets Directory

This directory contains generated PCB assets created by the CI/CD workflows.

## Directory Structure

- `pdfs/` - Generated PDF files from schematics and PCB layouts
- `gerbers/` - Gerber files for PCB manufacturing
- `drill/` - Drill files for PCB fabrication

## Important Notes

⚠️ **Do not commit generated files to Git** - These files are automatically generated by GitHub Actions workflows and should not be manually committed to the repository.

## Workflows

- **PR Builds**: When PCB files are modified in a pull request, the `pcb-build.yml` workflow automatically generates artifacts
- **Releases**: When a semantic version tag is pushed (e.g., `v1.0.0`), the `release.yml` workflow creates a GitHub release with attached PCB files

## Usage

### For Development
- Generated files are available as GitHub Actions artifacts on PRs
- Download artifacts from the Actions tab after PCB modifications

### For Manufacturing
- Download manufacturing packages from GitHub Releases
- Manufacturing packages contain Gerber and drill files ready for PCB fabrication
- Each release includes PDFs for review and assembly reference

## File Types Generated

### PDFs
- `MotionSimPCB-schematic.pdf` - Main schematic diagram
- `controllers-schematic.pdf` - Controllers schematic diagram  
- `MotionSimPCB-pcb.pdf` - PCB layout

### Manufacturing Files
- `*.gbr` - Gerber files (copper layers, solder mask, silkscreen, etc.)
- `*.drl` - Excellon drill files
- `*.zip` - Packaged manufacturing files ready for PCB manufacturer
